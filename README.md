# Real-time E-commerce Pipeline

A real-time data pipeline for processing e-commerce events.

## Project Structure

- `producer/` - Kafka producers for generating events
- `consumer/` - Kafka consumers for processing events
- `spark-streaming/` - Spark streaming jobs
- `postgres/` - Database scripts and configurations
- `schemas/` - Data schemas and definitions
- `docker/` - Dockerfiles for services
- `config/` - Configuration files
- `logs/` - Application logs
- `requirements/` - Python dependencies

## Getting Started

```bash
docker-compose up -d
```
